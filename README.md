# ER:LC Advanced Automation Bot — GitHub Pages policies

## Before publishing
1. Edit `docs/terms.html` and `docs/privacy.html`.
2. Replace every `[CONTACT EMAIL]` placeholder with an email address you monitor.
3. Verify the policy matches the exact bot version, enabled features, actual data stored, hosting provider, and retention settings.
4. These are general templates, not legal advice.

## Publish
1. Create a GitHub repository named `erlc-automation-legal` (or another name).
2. Upload the contents of this folder, including the `docs` folder.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/docs`, then save.
5. Wait for GitHub Pages to publish.

Replace `YOUR-USERNAME` with your GitHub username:
- Home: `https://YOUR-USERNAME.github.io/erlc-automation-legal/`
- Terms: `https://YOUR-USERNAME.github.io/erlc-automation-legal/terms.html`
- Privacy: `https://YOUR-USERNAME.github.io/erlc-automation-legal/privacy.html`

Use the Terms and Privacy URLs in your application registration form.
