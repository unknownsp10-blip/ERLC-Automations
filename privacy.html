DATA & PRIVACY

Privacy Policy

Last updated: November 5, 2026

1. Overview

This Privacy Policy explains how the ER:LC Advanced Automation Bot ("the Bot") handles information when a Discord server uses the Bot to connect to an ER:LC private server. The Bot is designed to keep each Discord server's configuration separate.

2. Information the Bot May Process

Depending on the features enabled, the Bot may process or store:

  • Discord identifiers: Discord server IDs, channel IDs, user IDs, and role IDs needed to check permissions, route messages, and run configured actions.
  • ER:LC connection information: The server API key supplied by an authorized administrator, connection status, and information returned by the ER:LC API.
  • Server and game information: Server name and status, player names or identifiers, teams, permissions, vehicles, queue information, command logs, kill logs, staff information, moderator calls, and emergency-call information, to the extent the API makes these available and relevant features are used.
  • Automation configuration: Automation names, triggers, conditions, actions, selected Discord destinations, custom variables, cooldowns, and related settings.
  • Operational records: Automation execution history, timestamps, success or failure status, and diagnostic information needed to operate and troubleshoot the Bot.
  • Interaction information: Information needed to respond to commands, buttons, menus, and other interactions with the Bot.

The Bot does not need your Discord password. Never submit a Discord password or other unrelated credentials to the Bot.

3. How Information Is Used

Information is used to authenticate connections, provide the Bot's features, evaluate automation conditions, execute configured Discord or ER:LC actions, prevent duplicate executions, enforce permissions and rate limits, maintain configuration after restarts, protect the service, and diagnose errors.

4. API Key Protection

The project is designed to encrypt ER:LC server API keys at rest and to keep them out of Discord messages and ordinary execution logs. Encryption depends on the operator correctly protecting the encryption key and hosting environment. Administrators should not share their API keys and should rotate a key if they believe it has been exposed.

5. Storage and Service Providers

Bot configuration and operational data are stored in JSON files on the machine or hosting environment where the Bot is deployed. The hosting provider may process technical information such as server logs, IP addresses, and resource usage under its own policies. Discord and ER:LC separately process information when the Bot communicates with their services. The Bot operator does not control their privacy practices.

6. Sharing

The operator does not intend to sell personal information. Information may be transmitted to Discord or ER:LC when needed to carry out an action configured by a server administrator. Information may also be disclosed if reasonably necessary to comply with law, respond to valid legal process, protect users or the service, or investigate abuse. Do not configure automations to send information to channels or people who should not receive it.

7. Retention and Deletion

Information is retained for as long as it is needed to operate the Bot, preserve server configurations, maintain execution history, or address security and operational issues. Retention can depend on the operator's hosting and backup settings. Removing a server's API key or deleting an automation does not necessarily erase historical records or backups.

8. Security

The project includes safeguards such as encrypted API-key storage, server-specific data separation, permission checks, and protected file writes. No internet-connected service or storage system can be guaranteed completely secure. The operator should restrict access to the hosting account, configuration files, backups, and encryption key.

9. Children

The Bot is not designed to collect information directly from children. Discord and Roblox/ER:LC have their own age requirements and policies. Users must comply with the age and consent requirements that apply to those services and their location.

10. International Processing

Depending on the Bot's hosting location and the locations of Discord, Roblox/ER:LC, and other service providers, information may be processed or stored in countries other than your own.

11. Changes to This Policy

This Policy may be updated as the Bot's features or data practices change. The "Last updated" date above indicates the latest revision. Material changes should be reflected on this page.
